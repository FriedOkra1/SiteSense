# SiteSense Landing Page Wireframe

## Section Flow
1. Header navigation with logo, brutalist links, install CTA.
2. Hero split: left headline & copy; right stack of annotated score cards.
3. Feature trio summarizing website analysis, extension audits, transparency window.
4. Transparency walkthrough timeline (three steps).
5. Privacy commitments grid (dos vs don'ts).
6. Open-source community banner with GitHub CTA.
7. Install section with marketplace buttons.
8. Footer grid of product/resources/docs/connect links.

## Layout Notes
- Strong black/white contrast, thick borders, asymmetric panels.
- Neon green highlights CTAs and positive signals; muted red flags cautionary notes.
- Typography mix: bold sans-serif for headlines, monospace for description/labels.
- Cards have frame borders, subtle glow, and label annotations.
- Ensure sections collapse vertically on mobile with preserved hierarchy.
